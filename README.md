## ⚡ Overview

The **SahamTeknikal Backend** is the analytical backbone and automated synchronization worker for the SahamTeknikal platform. It interfaces with upstream exchange feeds via the **Max Trade MCP Server**, applies rigorous mathematical models for technical breakouts and institutional bandarmology, evaluates historical signal win rates, and caches snapshots into **Supabase PostgreSQL**.

```
  ┌─────────────────────────────────────────────────────────────┐
  │                 Max Trade MCP Server (EOD / Broksum)        │
  └─────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │         Python Quantitative Engine (idx_scanner)            │
  │   - 3-Rule Screening (Fractal, MACD+EMA200, G-Acc)          │
  │   - Smart Money 3-Factor Scoring (Broker, Foreign, Trend)   │
  │   - Market Regime (Markup, Consolidating, Markdown)         │
  │   - Historical Win Rate Tracker (TP1, TP2, Naik Tanpa SL)   │
  └─────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │              Supabase PostgreSQL Database Cache             │
  │   (daily_market_dashboard, daily_screening_signals, etc.)   │
  └─────────────────────────────────────────────────────────────┘
```

## 🏗️ Architecture & Core Modules

### 1. Database Schema & Migrations (`supabase/migrations/`)
* **`20261128125100_redevelop_screener_v2.sql`**: Complete database schema supporting the v2 Command Center:
  * `idx_ticker_master`: Constituent metadata, sectors, sector slugs, and market cap weights.
  * `idx_eod_bars_cache`: Daily OHLCV bar caches with NBSA (Net Buy/Sell Asing).
  * `daily_market_dashboard`: Daily composite IHSG metrics, breadth counters, chart series, contributors, and quadrant data.
  * `daily_sector_snapshots`: Daily sector breakdown, constituent rankings, and historical sector charts.
  * `daily_screening_signals`: Historical and active signals generated by the 3-Rule Engine with target prices, stop losses, and smart money scores.

---

### 2. Quantitative Rules Engine (`scanner/src/idx_scanner/technical_rules.py`)
Implements mathematically rigorous technical rules without lookahead bias:
* **`fractal_levels(bars)`**: 5-bar Williams Fractal pivots confirmed strictly at $t = k + 2$.
* **`detect_ticker_signals_history(ticker, bars)`**:
  * **`FRACTAL_BREAKOUT`**: Close breaks above 5-bar upper fractal with $V_t \ge 1.20 \times \text{SMA}_{20}(V)$.
  * **`MACD_EMA200`**: MACD golden cross while price trades strictly above $\text{EMA}_{200}$.
  * **`G_ACC`**: Volume absorption ($V_t \ge 1.50 \times \text{SMA}_{20}$) at base support structure.
* **`classify_stock_regime(bars)`**: Evaluates stock regime into `MARKUP`, `CONSOLIDATING`, or `MARKDOWN`.
* **`classify_ihsg_regime(bars)`**: Evaluates composite index regime into `BULL`, `NEUTRAL`, or `BEAR`.
* **`compute_pivot_points(bar)`**: Floor Pivots ($P, S_1, S_2, R_1, R_2$).
* **`evaluate_signal_outcomes(signals, bars_by_date)`**: Rigorous statistical tracking of signal win rates across TP1, TP2, and Naik Tanpa SL (5D, 10D, Sampai Terbaru).

---

### 3. Smart Money & Market Scoring (`scanner/src/idx_scanner/smart_money.py`)
* **`compute_smart_money_score(broker_confidence, net_foreign, trend_aligned)`**: Evaluates institutional confirmation across 3 factors (Broker $\ge 60\%$, Foreign $> 0$, Bandarmology alignment).
* **`compute_ihsg_contributors(stocks, ihsg_base_cap)`**: Point-based index impact formula calculating top positive (penopang) and negative (pemberat) market movers.
* **`sector_to_slug(name)`**: URL-safe sector slug mapping for 11 IDX sectors.

---

### 4. Automated Bulk Sync Engine (`scanner/src/idx_scanner/mcp_bulk_sync.py`)
* Connects to the **Max Trade MCP Server** over JSON-RPC.
* Performs bulk retrieval of EOD histories and Broksum institutional records.
* Ingests, analyzes, computes daily dashboard snapshots, and upserts results into Supabase.

---

### 5. Scheduled Automation (`.github/workflows/scheduled-broker-flow.yml`)
* Automated GitHub Actions workflow running on market close (16:15 WIB / 09:15 UTC).
* Executes:
  1. `daily_broker_flow_sync.py` (Multi-horizon broker flow ingestion).
  2. `mcp_bulk_sync.py --incremental` (Daily screener, dashboard, and sector snapshots).
  3. Optional Vercel / frontend deploy trigger.

## 🧪 Testing & Verification

The backend test suite is powered by `pytest`:

```bash
cd scanner
.venv/Scripts/pytest tests/test_technical_rules.py
```

### Verified Test Cases:
1. `test_fractal_levels_and_anti_lookahead`: Guarantees Williams fractals are never confirmed early (zero lookahead bias).
2. `test_detect_signals_and_targets`: Verifies correct detection and entry/SL/TP calculations for `FRACTAL_BREAKOUT`, `MACD_EMA200`, and `G_ACC`.
3. `test_smart_money_scoring`: Validates scoring outputs (3/3, 2/3, 1/3, 0/3) and label mappings.
4. `test_regime_classification`: Confirms accurate transitions between `MARKUP`, `CONSOLIDATING`, and `MARKDOWN`.
5. `test_ihsg_regime`: Confirms `BULL`, `NEUTRAL`, and `BEAR` composite regimes.
6. `test_ihsg_contributors`: Validates market cap weighting and index point calculation.
7. `test_evaluate_signal_outcomes`: Verifies win-rate statistics calculation for TP1, TP2, and Naik Tanpa SL.
