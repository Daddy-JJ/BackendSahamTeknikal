# Chart V1 plan locator

Chart stages 1–6 are recorded released; this path is retained for vendored contract links.
[PLAN](../PLAN.md) owns authorized active work; [status](../IMPLEMENTATION_STATUS.md)
owns dated evidence/gaps. [Local Chart V1](../contracts/ticker-chart-v1.md) and its
checksum are the standalone protocol snapshot; [contract registry](../contracts/README.md)
maps source/RPC ownership. Do not replay completed chart implementation.

In the combined workspace, `docs/CHART_V1_IMPLEMENTATION_PLAN.md` owns the detailed
acceptance matrix and `docs/CHART_V1_LOCAL_VERIFICATION.md` owns dated verification.
Those parent files are optional external references and may be absent in a clone.
Use local versioned contract/status/source, report the missing reference and do not
infer fresh verification or invent unavailable requirements.
